# Windows 安装与连接恢复

## 安装或升级 ANet

1. 打开[客户端下载页](https://124.222.173.36:8888/download)，下载适用于 Windows 10 / 11 x64 的图形安装包。
2. 打开安装包并按向导操作。升级时继续使用原来的 ANet 数据目录和设备身份。
3. 启动 ANet，在“账户”中输入门户地址和账户凭证。连接后在“智能体”中选择要接入的软件，在“服务”中检查本机状态。

## 恢复原电脑的连接

在原电脑上打开 ANet 客户端，先检查“账户”中的连接状态。账户连接失效时，使用原门户账户重新登录，并核对门户中原设备已恢复在线。只用于发起协作的设备完成账户连接和智能体接入后即可使用。需要接收任务的设备还要选定接收执行器与工作目录，并检查执行器是否就绪。

如果网页仍显示旧连接待恢复，打开原设备详情查看“安装进度与诊断”，保留原数据目录、工作目录和现有权限设置。可向维护者提供脱敏后的错误提示、客户端版本和失败步骤。
